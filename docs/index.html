휠로 확대하고 싶으면 F5 설정에서 「휠 = 확대·축소」를 켭니다. 오른쪽 클릭하면 모든 기능이 메뉴로 나옵니다.

처음 설치할 때 파란 경고가 뜨면

ArdView 는 개인이 만든 프로그램이라 아직 코드 서명이 없습니다. 윈도우가 「PC를 보호했습니다」를 띄우면 아래처럼 누르세요.

  1. 「추가 정보」를 누릅니다
  2. 「실행」을 누릅니다

ArdView 는 무료입니다. 쓰다가 도움이 되었다면 후원으로 응원해 주세요.
